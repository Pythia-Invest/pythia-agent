# Security

Please do not disclose a suspected vulnerability in a public issue or pull
request.

Use GitHub's private vulnerability report for this repository:

<https://github.com/Pythia-Invest/pythia-agent/security/advisories/new>

Include the affected revision, impact, reproduction steps, and any suggested
mitigation. Remove credentials, personal data, investment records, and live
provider responses from the report. We will acknowledge the report and keep
discussion in the private advisory while it is assessed; this preview does not
promise a fixed response or remediation time.

Reports should cover the current `main` revision or, once published, the latest
signed stable release; older revisions are not supported. Pythia currently
binds its services to localhost, but that is not a substitute for host
security. The managed-source approval instruction is advisory and is not an
access-control boundary.

## Publication gate

Repository maintainers must enable and verify GitHub private vulnerability
reporting before making the project public. If the link above does not open a
private report, do not publish sensitive details; the security intake is not
ready.
