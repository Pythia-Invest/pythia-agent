# Investment workspace

Your research lives here: Markdown notes, datasets, calculations, scripts,
images, PDFs and other useful files. These are ordinary files you can use
outside Pythia. Pythia creates these starter documents once; updates preserve
your changes.

Ask Pythia to save useful research and link to it in chat. Read it beside the
conversation or browse and search independently in Workspace. Desk currently
supports viewing, downloading and referencing files; ask the agent for changes
or use your own editor. Uploaded chat originals are kept by the chat integration;
the agent can copy useful material into research without removing originals.

You do not need a strategy to work. If separate goals or assumptions help,
use a brief at `strategies/<name>/README.md` and explicitly start a chat with
that strategy. Strategies share research; reading another brief does not
change a conversation's scope. See [Strategies](strategies/README.md).
