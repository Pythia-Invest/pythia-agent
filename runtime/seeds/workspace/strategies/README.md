# Optional strategies

A strategy is a convenient way to keep distinct goals, risk constraints,
assumptions and decisions together. It is not a separate research library,
Hermes profile, investment account or authorization to commit capital.

When useful, ask Pythia to create `strategies/<name>/README.md`. Write the brief
in ordinary Markdown, with an optional heading for its display name. There is
no required metadata schema. Link to shared research instead of duplicating it;
keep strategy-specific interpretations and decisions with the relevant brief.

Workspace discovers these briefs so you can explicitly start a scoped chat.
General research and chat work without any briefs. A hypothetical strategy or
comparison remains exploratory until you adopt it.
