# Durable note discipline

Search relevant filenames and contents before creating a durable note. Read
likely matches and prefer a targeted revision when one already owns the subject.
Folder structure and document format should serve the work, not a case schema.

Keep source links and publication or as-of dates close to material claims. Add
an access date when it explains what was available. Label estimates, assumptions
and interpretation separately from evidence. Record units, currency, periods
and calculation inputs so another reader can check the result. Missing data is
not zero; preserve useful partial results and their limits.

For a material conclusion or decision, record the reasoning and relevant scope.
Distinguish a proposed rule, a temporary scenario and an adopted strategy change.
When revising research, check its current contents and preserve unrelated work;
do not silently turn an old conclusion into a current fact.

Use ordinary Markdown links between documents and supporting artifacts. Keep
relative links valid when organizing files. Leave uploaded chat originals in
place; copy useful source material when durable research needs its own file.
Return links to the artifacts you actually saved so the investor can inspect
them. Never claim an output exists or was updated without successful tool work.
