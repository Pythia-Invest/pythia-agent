# Selective salvage boundary

Pythia's public repository has fresh history and is the only implementation
authority. Earlier applications, a retained backup, and the live Hermes lab are
evidence, not dependencies. Nothing is bulk-copied and no private path appears
in public source or build instructions.

| Candidate | Ruling | Retained transformation and boundary |
| --- | --- | --- |
| Current UI tokens, accessible primitives, icons, and their focused tests | Adapt | Copy only reviewed source, rename product assumptions, replace data with synthetic examples, remove unused dependencies, and keep Design Lab development-only. |
| Current Design Lab interaction catalogue | Adapt | Preserve useful component states, not application data or internal docs; exclude its output and guidance from runtime/model-visible closure. |
| Experimental Desk interaction evidence | Adapt | Rebuild against the narrow authenticated Hermes session/run contract; retain useful chat, history, approval, cancellation, readiness, and empty/error interaction ideas, not host paths or speculative DTOs. |
| Experimental analytical runner behavior | Adapt | Reimplement the smallest portable Python/TypeScript execution boundary with explicit timeout/cancellation and bounded JSON; remove shell-, Bun-, host-, and workspace-specific assumptions. |
| SEC and EODHD investment skill procedures | Adapt | Retain only the operations in `financial-data.md`; rewrite public instructions and use synthetic provenance-linked fixtures. |
| Investment-memory instructions | Adapt | Retain the useful distinction between brief Hermes memory and authoritative Markdown; remove personal knowledge, portfolio content, and machine paths. |
| Hermes native profile, external-skill, plugin, session, and run behavior | Adopt | Consume the exact qualified upstream commands/APIs. Pythia adds lifecycle serialization, redaction, process supervision, and bounded response projection only where this contract requires them. |
| Basic Memory Markdown/FTS behavior | Adopt | Run the exact separate package with the qualified configuration; never copy its code or use the Hermes memory-provider integration. |
| Older private product contracts, application loop, database/queue/object-store architecture | Reject | They describe another product authority and would reintroduce a second agent/state plane. |
| Backup-branch Hermes patches, vendored source, submodules, and replacement agent loop | Reject | The runtime dependency must remain exact, unmodified, Pythia-owned, and replaceable. |
| Fleet, cloud, AWS/SSM/Terraform, Postgres/pg-boss/S3, Docker, proxy, Tailnet, and host-service code | Reject | These are outside the local product/runtime boundary. |
| Experimental structured monitor plugin/database, cron watch behavior, and monitoring data | Reject | Monitoring is not in the first slice and would add a second durable control plane. |
| Generated indexes/databases/caches, sessions, logs, model output, credentials, environment files, and secrets | Reject | Device state is not source and must never be copied or committed. |
| Lab workspace, knowledge, cases, portfolio records, people, sources, and other personal data | Reject | These are private investor-owned data, not fixtures or seeds. |
| Provider response data | Reject by default | SEC/EODHD data is not automatically redistributable; use synthetic schema-derived fixtures unless an individual upstream fixture has proven publication rights. |
| Unneeded lab packages and transitive conveniences | Reject | Dependencies enter only through an exact managed manifest for a qualified operation. |
