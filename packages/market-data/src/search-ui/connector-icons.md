# Connector icons

Official website icons of connector plugins, embedded in the feature frontend so
search does not contact third-party image hosts. Keys are plugin ids; a plugin
without an entry shows a neutral mark. Brand assets remain the property of their
respective owners and are used only to label the owner's own connector.
Retrieved 2026-09-22 (SEC 2026-09-24); larger originals downscaled to 32 px PNG.
